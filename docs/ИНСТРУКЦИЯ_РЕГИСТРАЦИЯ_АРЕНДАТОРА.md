# Инструкция: регистрация арендатора в Pass

Система электронных пропусков **Pass** (pass.mstyle.ru)  
Для **владельцев компаний-арендаторов** (не для сотрудников БЦ и не для охраны)

---

## Кому подходит эта инструкция

| Роль | Как появляется в системе |
|------|--------------------------|
| **Арендатор (владелец компании)** | Самостоятельно регистрируется на сайте |
| **Сотрудник компании** | Приглашает владелец из раздела «Профиль» (ссылка на email, не эта инструкция) |
| **Ресепшн / админ БЦ** | Создаёт администратор |

Если вы сотрудник арендатора — попросите владельца компании отправить приглашение из профиля.

---

## Что нужно подготовить

1. **Корпоративная почта** в зоне **`.ru`**, **`.рф`** или **`.су`**  
   Пример: `ivanov@company.ru`
2. **Название компании** — как в договоре / на табличке (например, `ООО «Ромашка»`)
3. **ФИО** ответственного лица
4. **Пароль** — не короче 6 символов
5. По желанию — **мобильный телефон** в формате `+7…` (для входа и SMS-кода, если SMS включено)

### Какая почта **не** подойдёт

Обычно **не принимаются** публичные сервисы, например:

- Gmail, Outlook / Hotmail, Yahoo, iCloud, ProtonMail и аналоги  
- Адреса **не** в зоне `.ru` / `.рф` / `.su`

Используйте рабочую корпоративную почту компании.

---

## Шаг 1. Откройте страницу входа

1. Перейдите на сайт Pass: **https://pass.mstyle.ru**
2. Откроется страница входа (или перейдите по ссылке «Вход» / `/login`)
3. Выберите режим **«Регистрация»** (не «Вход»)

---

## Шаг 2. Заполните анкету

Укажите:

| Поле | Обязательно | Комментарий |
|------|:-----------:|-------------|
| Фамилия | да | |
| Имя | да | |
| Отчество | нет | по желанию |
| Компания | да | полное или краткое юр. название |
| Email | да* | корпоративный, см. требования выше |
| Телефон | нет / да* | формат `+7 9XX XXX-XX-XX` |
| Пароль | да | минимум 6 символов |
| Повтор пароля | да | должен совпасть с паролем |

\* Канал подтверждения:

- **По email** — код придёт на указанную почту (основной способ)
- **По SMS** — если функция включена администратором; код на телефон (не чаще 1 раза в 5 минут)

Нажмите кнопку отправки кода / продолжения регистрации.

---

## Шаг 3. Подтвердите код

1. Откройте письмо (или SMS) с **6-значным кодом**
2. Код действует **15 минут**
3. Введите код на сайте
4. Если письма нет — проверьте папку **«Спам»** / «Промоакции»
5. Если код истёк — запросите код **заново** (для SMS — не чаще чем раз в 5 минут)

После успешного ввода кода **учётная запись создаётся**.

---

## Шаг 4. Ожидание активации администратором

Сразу после регистрации доступ **ещё не полный**:

- Заявка попадает администратору на проверку
- Пока заявка **не одобрена**, заказ пропусков **недоступен**
- На сайте может отображаться сообщение:  
  *«Заявка на регистрацию ожидает подтверждения»*

### Что делает администратор

1. Проверяет данные компании и контакты  
2. **Одобряет** регистрацию  
3. **Привязывает офисы** компании к вашему аккаунту  

Без закреплённых офисов заказ пропусков также будет недоступен.

---

## Шаг 5. Первый вход после одобрения

1. Откройте **https://pass.mstyle.ru/login**
2. Войдите:
   - **email**, или  
   - **телефон** (+7…), или  
   - логин (если выдан)
3. Введите **пароль**, заданный при регистрации

После входа станут доступны разделы арендатора, в том числе:

- заказ пропусков  
- список своих пропусков  
- профиль и (для владельца) приглашение сотрудников  

---

## Что делать дальше (кратко)

### Заказать пропуск

1. **Пропуска** → **Заказать пропуск**  
2. Тип пропуска, данные гостя, дата (ближайшие рабочие дни), офис  
3. При необходимости — авто (госномер), комментарий, отправка ссылки гостю на email  
4. Отправить заявку → открывается **электронный пропуск** со ссылкой и QR  

### Добавить сотрудника компании

1. **Профиль** → блок **«Сотрудники компании»**  
2. ФИО, email сотрудника → **Отправить приглашение**  
3. Сотрудник переходит по ссылке из письма (действует **72 часа**) и задаёт пароль  
4. Лимит: **не более 3 сотрудников** на компанию (кроме владельца)

### Если забыли пароль

1. На странице входа — **«Забыли пароль?»**  
2. Укажите **email** аккаунта  
3. Введите код из письма и новый пароль  

Если email не подходит / не помните — обратитесь к администратору БЦ (контакты часто указаны на странице входа или в «Помощь»).

## Частые вопросы

### «Не приходит код»

- Проверьте **Спам**  
- Убедитесь, что email **корпоративный** и в зоне `.ru` / `.рф` / `.su`  
- Дождитесь **15 минут** и запросите код снова  
- Для SMS: не чаще **1 раза в 5 минут**; если SMS отключено — регистрируйтесь **по email**

### «Регистрация отклоняет email»

- Нельзя Gmail, Outlook, iCloud и другие публичные сервисы  
- Нужна почта вида `имя@ваша-компания.ru`

### «Вошёл, но не могу заказать пропуск»

1. Заявка ещё **не одобрена** администратором — дождитесь активации  
2. Одобрили, но **не привязали офис** — напишите администратору БЦ  
3. Вы **сотрудник** без прав / отключён владельцем — уточните у владельца компании

### «Нужен доступ второму человеку из компании»

Не создавайте вторую регистрацию компании.  
Владелец добавляет сотрудника в **Профиль → Сотрудники**.

### «Мы уже зарегистрированы на сайте M-Style»

Регистрация в **Pass** — отдельная.  
Даже если вы резидент на сайте управляющей компании, в Pass нужна своя учётная запись (или доступ, который выдаст администратор).

---

## Контакты при проблемах

- Контакты на странице **входа** / в блоке **«Помощь»** в приложении  
- Ресепшн / администратор бизнес-центра  
- Управляющая компания (если так принято в вашем БЦ)

Укажите при обращении:

- название **компании**  
- **email**, с которого регистрировались  
- **телефон** (если указывали)  
- что именно не получается (скрин ошибки)

---

## Краткая схема

```
1. pass.mstyle.ru → Регистрация
2. ФИО + компания + корпоративный email + пароль
3. Код из письма / SMS (15 мин)
4. Ожидание одобрения администратором + привязка офисов
5. Вход → заказ пропусков
```

*Документ описывает регистрацию **арендатора (владельца компании)** в системе Pass.  
Сотрудники компании подключаются только по приглашению владельца.*
