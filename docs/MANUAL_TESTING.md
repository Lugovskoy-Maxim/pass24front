# Для ручного тестирования

Раздел находится на странице `/admin/integration`. Существующий режим
Mock/dev работает отдельно и не изменяется.

1. Укажите почту для кодов: `ninzak@ya.ru`.
2. Нажмите «Включить тестовый режим».
3. Нажмите «Подготовить профили».
4. Входите в Mstyle по email или телефону нужного профиля.

Коды создаются случайно, живут обычное время и проходят обычные ограничения.
SMS Aero для тестовых номеров не вызывается. Код, имитирующий SMS, приходит на
указанную почту. Режим автоматически выключается через 24 часа.

## Банковские реквизиты

Для ООО используется счёт вида `40702`, для ИП — `40802`. БИК `044525225`
принадлежит действующему ПАО Сбербанк. Номера расчётных счетов синтетические,
но имеют корректный контрольный разряд. Корреспондентский счёт сверяется по
отдельному правилу.

Проверяются:

- БИК — ровно 9 цифр;
- расчётный счёт — ровно 20 цифр и контрольная сумма по БИК;
- корреспондентский счёт — ровно 20 цифр и контрольная сумма по БИК.

Тестовые реквизиты нельзя использовать для реальных платежей.
