# Планшет переговорной

Страница `/kiosk` работает в книжной и альбомной ориентации и использует тему,
цвета и бренд сайта. Обычные меню, подвал, предложения установки PWA и уведомления
на ней не показываются.

## Первое включение

1. Разверните изменения frontend и backend вместе.
2. Откройте `https://<адрес Pass>/kiosk` на планшете.
3. Нажмите «Войти как администратор». Нужны права `admin.panel` и
   `bookings.manage`. Администратор БЦ видит только свой каталог помещений.
4. Выберите переговорную и нажмите «Привязать планшет».
5. В Fully Kiosk Browser задайте HTTPS-адрес `/kiosk` в **Web Content Settings → Start URL**.
   Если используете **URL Whitelist**, добавьте полный адрес страницы, например
   `https://pass.example.ru/kiosk*`. Включите **Kiosk Mode**, задайте PIN выхода
   и отключите автозаполнение паролей в Android. Сохраняйте данные сайта при
   перезапуске, чтобы планшет оставался привязанным. Оставьте **Auto Reload on Idle**
   выключенным, чтобы браузер не прерывал вход и оплату.
   [Настройки веб-контента](https://www.fully-kiosk.com/docs/en/configuration/web-content)
   · [Настройки автоматической перезагрузки](https://www.fully-kiosk.com/docs/en/configuration/web-auto-reload)
   · [Настройки режима киоска](https://www.fully-kiosk.com/docs/en/configuration/kiosk-mode)
6. Для обычных пользователей должны быть назначены офисы и опубликованы тарифы
   переговорной. Приём бронирований должен быть включён в Pass.

## Поведение

- Анонимное расписание на сегодня обновляется каждые 15 секунд. Если данные
  старше 45 секунд или запрос не удался, создание брони блокируется; прежнее
  расписание помечается неактуальным. Время — московское, с коррекцией по серверу.
- В форме входа можно выбрать логин, российский мобильный номер или почту.
  На привязанном планшете активный арендатор или сотрудник может выбрать
  «Телефон» → «Войти по СМС». Шестизначный код действует пять минут.
  Для отправки backend нужны `SMSAERO_EMAIL`, `SMSAERO_API_KEY` и
  `SMSAERO_TEXT_SIGN`. Кнопка «Забыли пароль?» показывает QR-код на
  страницу восстановления Pass для телефона посетителя.
- Кнопка «Войти по QR-коду» позволяет подтвердить вход из активной сессии Pass
  в браузере телефона. Сверьте четырёхзначный код на обоих экранах и нажмите
  «Подтвердить вход». QR действует одну минуту и используется один раз.
- Пользователь выбирает свой офис, дату по московскому времени и непрерывные
  свободные интервалы. По умолчанию открывается сегодня, прошедшие даты недоступны.
  При наличии прав пользователь применяет бесплатные минуты, получает серверный
  расчёт и подтверждает бронь. Действуют существующие права, тарифы и проверки
  конфликтов. Повтор запроса использует тот же ключ бронирования.
- При оплате картой киоск создаёт бронь с временным удержанием интервала.
  Посетитель сканирует QR-код и вводит данные карты на странице ЮKassa на своём
  телефоне. Киоск проверяет результат каждые пять секунд. Для онлайн-оплаты
  нужны перенесённые в Pass настройки ЮKassa с автоматическим списанием и
  рабочий фоновый обработчик платежей. При включённой выдаче чеков профиль должен содержать
  подтверждённую почту или телефон.
- Бронь за нулевую сумму и бронь с оплатой наличными используют обычный сценарий
  подтверждения. После создания на экране виден фактический статус брони.
- JWT посетителя/администратора хранится только в памяти страницы, не использует
  обычную сессию сайта и удаляется после бронирования, 60 секунд бездействия,
  ухода со страницы или скрытия вкладки. За 15 секунд до выхода появляется
  предупреждение. Перезагрузка требует нового входа.
- При переходе к оплате сессия посетителя завершается сразу. Экран с QR-кодом
  закрывается через три минуты бездействия. Закрытие экрана не отменяет платёж
  и не освобождает интервал раньше срока.
- Токен устройства хранится отдельно в localStorage (`pass24_kiosk_device`).
  Он разрешает только чтение обезличенного расписания одной комнаты. На сервере
  хранится SHA-256 токена в `mstyle_ops_kiosk_devices`; личные данные брони
  в ответ `/api/kiosk/status` не включаются.

## Смена переговорной и отзыв доступа

Нажмите шестерёнку внизу, войдите как администратор и выберите новую комнату
или «Отозвать доступ планшета». Прежний токен отзывается на сервере.
Если локальные данные браузера уже удалены или планшет потерян, администратор
может отозвать запись в `mstyle_ops_kiosk_devices`, установив `revoked: true`.
Не размещайте токен устройства в URL или публичных материалах.

В настройках планшета раскройте «Настройки ЮKassa», чтобы проверить состояние
онлайн-оплаты. Если конфигурация недоступна, форма бронирования предложит наличные.

В Mstyle параметры хранятся в опции WordPress `tf_mstyle_yookassa_settings`.
Нужны активная интеграция (`enabled`), ID магазина (`shop_id`), секрет магазина
(`secret_key`) и автоматическое списание (`capture`). Для Pass эти параметры
переносятся в зашифрованные настройки через
[экспорт и импорт операций](OPERATIONS-MIGRATION.md#экспорт-импорт-и-сверка).
Worker в Pass создаёт ссылку оплаты, когда владелец операций переведён в
режим `pass`. Webhook ЮKassa продолжает приходить в WordPress на
`/wp-json/tf-mstyle-theme/v1/yookassa/webhook`, откуда Mstyle передаёт
событие в Pass. QR-коды оплаты и восстановления открываются на телефоне.

Для тестового бронирования используйте учётку арендатора из тестовых данных.
Проверьте активный назначенный офис, доступный тариф выбранной переговорной
и режим операций `pass`. Если офисов несколько, выберите офис с доступом к
переговорной.

Ограничение системных кнопок и приложений обеспечивает Fully Kiosk/управление
Android, а не веб-страница. Проверяйте блокировку на конкретной модели Huawei.

## Проверка на планшете перед выкладкой

1. В Fully Kiosk Browser проверьте расписание в обеих ориентациях. Длинное
   название комнаты и часы должны целиком помещаться в шапке.
2. Откройте вход с паролем, вызовите клавиатуру и прокрутите до кнопки «Войти».
   Затем проверьте вход по СМС, QR-код восстановления пароля и QR-вход
   с активной сессией Pass на телефоне.
3. С главного экрана выберите «На завтра». После входа должна открыться
   завтрашняя дата. Выберите интервал и убедитесь, что итог и кнопка
   оформления доступны в обеих ориентациях.
4. Для проверки оплаты используйте тестовый магазин ЮKassa в тестовой среде.
   Проверьте создание QR-кода, завершение оплаты на телефоне и появление
   номера и фактического статуса брони на планшете.
5. После выхода или минуты бездействия на экране должна остаться только
   информация, доступная следующему посетителю.

## Запланировано: видеозаставка

- После настраиваемого времени бездействия на экране расписания киоск должен
  запускать полноэкранный MP4 без звука и воспроизводить его по кругу.
- Первое касание должно убрать заставку и вернуть расписание. Во время входа,
  настройки, бронирования и оплаты заставка не запускается.
- Для реализации нужен MP4-ролик. Перед выпуском нужно проверить автовоспроизведение
  и возврат к расписанию в Fully Kiosk Browser на планшете.
