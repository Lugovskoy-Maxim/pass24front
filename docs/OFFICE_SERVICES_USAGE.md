# Настройка обслуживания и прайса офисов

## Порядок настройки

1. Откройте «Администрирование → Прайс и категории». Главный администратор меняет названия, цвета и порядок категорий. Категория связанного офиса продолжает обновляться с сайта через MySQL; «Стандарт+» распознаётся как `standard_plus`.
2. Добавьте нужные услуги: публичный IP, лифт, роутер, переговорная и любые другие. Заполните название, описание и БЦ. Общие для всех БЦ услуги изменяет главный администратор; администратор БЦ работает со своим БЦ.
3. Для каждой категории включите «Настроить условия», затем вручную задайте показ, возможность заказа, условия, единицу расчёта, цену и описание. Можно выбрать «Платно», «Включено», «Бесплатно в пределах лимита», «Недоступно» или «Стоимость уточняется». Цены и условия примеров автоматически не создаются.
4. Для переговорной укажите её номер из существующего каталога бронирований, расчёт по часам и, при необходимости, бесплатные минуты в месяц. Одной переговорной назначайте один активный тариф в пределах БЦ. Не заполненные, скрытые и архивные условия не открывают бронирование по цене другого типа офиса.
5. Откройте нужный офис в разделе «Офисы» и нажмите «Изменить». Под основной формой находится блок «Обслуживание офиса»: текущий сервис, интернет, индивидуальные условия и видимость.
6. Введите параметры интернета, сети, публичного IP, роутера и инструкции. На вкладке «Видимость» отметьте только сведения, которые должен видеть арендатор. Для услуг включите «Услуги и прайс». Рядом доступен предварительный просмотр. Сохраните обслуживание отдельно от основной формы офиса.

## Что увидит арендатор

В профиле сайта и Android офис показывает опубликованные администратором сведения. Раскрывающийся блок содержит интернет, включённые услуги и доступный прайс. Нажатие «Заказать» создаёт обращение для выбранного офиса; «Забронировать» открывает переговорные. В обращении сохраняются цена и условия на момент заказа.

Для переговорной арендатор выбирает офис, дату, свободное время и проверяет расчёт перед подтверждением. Бесплатные минуты доступны только для условий, предусматривающих лимит. Доступность времени и достаточность остатка сервер повторно проверяет при создании брони.

## Лимиты, совместимость и выпуск

- Бесплатные минуты принадлежат общему ресурсному профилю компании. Сотрудники используют общий остаток в пределах существующих разрешений. Несколько офисов не создают несколько балансов: применяется максимальный вручную заданный лимит назначенных офисов.
- Начисление и обновление периода выполняются существующей системой учёта часов. Уже начисленный остаток не сбрасывается при редактировании категории или прайса; новый месячный лимит применяется при следующем начислении. Текущий остаток при необходимости корректируется в существующем разделе часов с записью в истории.
- Для переговорных, которым ручной тариф ещё не назначен, сохраняется существующий каталог и порядок расчёта. После назначения ручного тарифа применяется точное условие категории офиса. Заказы и бронирования сохраняют свои условия; изменение прайса не переписывает историю.
- При конфликте одновременного редактирования обновите карточку перед повторным сохранением.
- Сервер добавляет справочник категорий и пустые настройки. Рабочие цены и параметры офисов заполняет администратор.
- Запись заявок и бронирований остаётся под существующим переключателем владельца операций. В `paused` и `mstyle` запись через новый интерфейс выключена; для приёма операций требуется настроенный режим `pass`. Этот режим доработка самостоятельно не переключает.
- Каталог переговорных требует уже настроенного соединения Pass с каталогом M-STYLE. Изменение исходного WordPress-сайта и переключение его режима обмена в эту поставку не входят.
- Перед выпуском проверьте резервную копию, рабочее подключение MySQL, выбранный БЦ и актуальные разрешения пользователей. Затем выпускайте сервер, сайт и Android последовательно. Текущая работа не выполняет публикацию или изменение рабочей базы.
